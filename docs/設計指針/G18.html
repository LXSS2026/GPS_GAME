G18 マクロのゲーム進行(図解)

2026-10-15 作成、同日の手順 4・4.5・5 の実装後に更新。現在の理解と決定範囲を 1 枚にまとめた図。A は段階の進行(G4)、B は各段階で回る一つの経済(G3 の構想図を実装の状態で塗り分け)、C は時間の刻み(G12 #16)。緑 = 実装済み、橙 = 設計案(G17、承認待ち)、灰 = 未着手。

読み方

流れ現状
物の流れ(上段): 鉱脈 → 工場 → 機体 → 隊 → 戦場実装済み。鉱石の品質・レシピの品質下限・部品の品質 → 機体の性能値 → 戦闘の命中と耐久まで一本につながっている(G13・G14・G16)
人と支持の流れ(下段): 農地・水源 → 都市 → 労働者・徴兵、税・支持率 → 政治 → 政策実装済み(G17・G19)。設備の要員と隊の要員は都市の労働人口から引く
段階の昇格: 人口 + 支持率G4 の 4 段階。人口の下限(100 / 1,000 / 10,000)と支持率 60% が 30 日(G17 #11 確定)
政治と外交第 1 段階まで実装済み(G19・G20)。決着(制覇か同盟網、敗北は征服か失脚)は計算で判定し、通知を出して計算は止めない
時間一つのティックループ(60/秒)。都市は 1 時間ごと、人口の増減と外交は 1 日ごと、人物は 1 か月ごとに同じループの中で更新する
